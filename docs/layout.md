# 源码导航

| 目录 | 内容 |
| --- | --- |
| `src/host/` | DSH 插件入口、会话操作、连接配置、反馈与静态资源注册 |
| `src/client/` | DSH 页面入口、音频、输入框同步、设置页和教学 |
| `src/shared/` | 模式状态与会话目录规则 |
| `config/` | DSH bundle 声明 |
| `assets/tutorial-audio/` | 教学音频与校验清单 |
| `tests/unit/` | 模块单元测试 |
| `tests/browser/` | 设置、教学和反馈的浏览器测试 |
| `tests/host/` | 隔离 DSH 安装与运行测试 |
| `scripts/` | 测试入口与发布内容检查 |

公开入口由 `package.json` 的 `exports` 和 `dsh.bundle` 指定，不依赖根目录文件名。
浏览器资源只从显式清单提供，不会把整个源码目录作为静态目录暴露。

## 命名与兼容

新增代码使用 `duet` 命名；代码模块使用短文件名，由目录表达职责。
地址等配置优先读取 `DUET_*`，旧环境变量仅在 `src/host/environment.mjs` 兼容。
公开试用访问凭证与默认地址统一放在 `src/host/service-defaults.mjs`；不读取本地或环境变量中的鉴权凭证。
该凭证仅用于内置服务地址，切换到其他服务不会携带它；连接配置文件只保存地址。

旧 HTTP 路径、协议字段、Cookie、浏览器存储键和互斥锁标识保持稳定，
确保升级不会清除授权、快捷键、麦克风选择或反馈身份，也不会让新旧页面同时采集音频。
旧浏览器模块地址由 `src/host/assets.mjs` 提供兼容导出；新页面使用 `/duet/assets/`。
`duplex` 作为全双工模型的协议字段仍保留，不是插件品牌名称。

两种语音模式都要求 DSH 已有 workspace：浏览器在授权和音频启动前检查，Host 在连接外部服务前再次检查。
会话编号由 `browserSessionCatalog` 统一供 RPC 与状态同步使用，排除归档及子代理会话。
DSH 0.1.5 使用其已保存的活动排序，0.1.6 的近期排序根据实时更新时间计算；手动排序保留页面设置。
待答问题同时支持 0.1.5 的 `pendingInteractions` 和 0.1.6 的 `sessionStatus.pendingInteraction`。

## 页面与连接归属

停止执行使用 `stop_task_v1` 能力协商，同时覆盖当前会话和指定名称/序号会话。
只在 DSH Host 提供官方 cancel API、页面支持连接归属校验时声明该能力。
执行前读取该次 turn 的不透明标识；取消请求校验此标识并去重，不能影响后来启动的任务。
没有已观测的运行 turn 时失败，不猜测其他后台任务；当前会话来自连接所属页面。
取消受理不等于已终止；仅在收到真实 turn/end aborted 后发布终止结果，保持 failed 状态。
“暂停”表示中止本次执行，不提供长期 goal 的暂停/恢复，也不清空 DSH 待处理队列。

播放打断使用 `audio_stop_candidates_v1` 协商。

普通页面不发布或跟随全局会话焦点，也不响应跨页面输入框广播。
交互连接持有独立的 connection ID：读取和写入使用本页面输入框，发送队列通过
`X-Duet-Browser-Client` 定向给连接所属页面，其他页面及旧连接不能领取。
新建、切换和分叉完成后只导航当前页面；断开连接会中止轮询及待处理的本地操作。
语音新建会话使用连接所属页面当前选中的 workspace；无法确定时不创建，不回退到进程目录。
页面目录和反向 RPC 保留空白会话到浏览器，再按页面焦点筛选；当前新会话可立即输入和发送，其他空白会话不占编号。
教学只在用户确认发送时临时开启定向桥接，不依赖语音模式，也不启用麦克风。

连接日志记录浏览器插件版本、Host 插件版本、随机页面 ID、连接 trace ID 和
`connection_owner_v1` 绑定协议。浏览器错误诊断另含时间、页面可见性、模式、错误码及
有限长度的异常栈；音频准备事件包含采样率、AudioContext 状态和浏览器 User-Agent。
这些归属标识不是鉴权凭证，不向模型正文注入诊断信息。

播报与交互连接共用 `duet_session_v1` 元信息：插件/Host 版本、模式、页面 ID、
连接 trace ID、页面绑定协议、实际连接地址和引导配置。旧页面缺少 trace ID 时生成
当次连接的随机 ID，不存为长期用户 ID。调度协议仍使用 `online` / `external_only`，
界面模式为 `online` / `tts_only`；两者不可混作 DSH 任务会话 ID。
增加 Desktop 版本的反馈兼容性：适配桌面请求桥接，使文字反馈与会话评分正常工作。
Web 保持现有行为；Desktop 主页面与设置页兼容并发初始化、刷新和重新打开。
反馈和设置写入仍保留 DSH 鉴权与请求校验；兼容信息不放入 URL 或诊断日志。
授权版本保持 v3，两种模式共用一次同意。
DSH 会话目录、输入框和任务结果按既有功能传输，本次不增加播报模式的麦克风或草稿采集。

## 默认入口与连接选择

`DEFAULT_DUET_URL` 使用 `wss://duet-router-acc.router.dsh-duet.com/ws?protocol=realtime_v2`。
推荐地址与默认地址相同时只进行一次直连。
已保存的旧默认入口和旧网关地址在加载配置时迁移为当前默认入口；不再作为鉴权或连接兼容项。
迁移原子保存并清除旧明文许可，磁盘暂时不可写时也可使用新入口；自定义地址不变。
公开服务从默认入口的 `/api/connection-info` 获取推荐地址，
推荐地址持久化在 DSH_HOME/dsh-duet/endpoint-discovery.json。启动和连接时检查，
每 24 小时最多后台尝试刷新一次（失败也计入），连接不等待刷新。刷新失败保留旧推荐，
没有缓存时使用固定入口；推荐连接握手失败时回退固定入口。缓存不含凭证。
自定义服务不参与公开服务地址发现，也不会携带公开服务凭证。

超过 8000 字符的任务结果在发送前改为“内容较长，请到会话查看”的短通知，
完整结果仍保留在 DSH，不截断代码充当摘要，不关闭连接或阻塞后续播报。
会话标识只用于操作路由，缺失名称或名称等于标识时统一使用“未命名会话”。
会话操作兼容 DSH IM 会话的冒号标识（如 `im:wecom_…:dm:…`）；路径中支持冒号的
URL 编码并只解码一次，输入框读写、发送、切换、重命名和分叉使用原始会话标识。
待答问题也支持新版 DSH 的多段标识。取消时使用对应版本的原生接口；仅能隐藏的
问题不报告“已取消”，以免把仍在等待的任务误当成结束。

2026-10-10 隔离验证：官方 npm `latest` 为 DSH `0.2.0-rc.2`，`alpha` 为
`0.2.1-alpha.2`，两者的安装、双模式、输入框操作、待答问题显示与回答测试通过。
Desktop 另有 transport/设置/反馈桥接回归；这不替代各操作系统原生桌面应用的人工验收。

推荐地址允许裸 IP/域名以及 HTTP、HTTPS、WS、WSS URL；裸地址维持 WS 的兼容默认值。
显式 HTTPS 转为 WSS，WSS 保持不变，统一补齐 `/ws?protocol=realtime_v2`。
选中 WSS 后，模型信息、服务通知和反馈等 HTTP 请求使用 HTTPS；域名仍用于 TLS 校验，
不因 DNS 地址固定而改用 IP 校验证书，也不跳过证书验证。
推荐地址只支持根路径或 `/ws`，端口为默认端口、80 或 443。

Desktop 的语音连接使用 DSH 提供的 `__DSH_TRANSPORT__.streamBaseUrl`，不从
`dsh-app://app/` 拼接 WebSocket 地址；Web 使用文档 base URI 并保留挂载路径。
Desktop 设置页在当前窗口的可关闭 iframe 弹层中打开，Web 仍使用新标签页。
插件卸载或控件重新挂载时清理设置弹层及其监听器。

折叠侧栏仅显示 `D` 与连接状态点，不占用 DSH 设置入口的空间；悬浮、点击或键盘聚焦后，
交互、播报与设置在顶层浮层中展开，不受侧栏 overflow 裁切。移出后延迟收起，支持 Escape、
点击外部关闭以及教学时保持可见。展开侧栏仍使用完整 duet 标识与三个操作入口。

`harness_sync_v1` 统一协商会话状态、待答问题和任务结果；初始快照被确认后才停止相应查询，
旧版本或协商失败保持增量查询兼容。只有连接所属页面发布会话顺序、焦点和待答问题，
状态使用递增序号并合并尚未发送的更新，问题已回答或撤销也会同步。结果确认表示接收而非
播报完成；未确认可重试，断线按来源 epoch 与游标恢复并去重。

两种模式共用 DSH 本地事件 WebSocket；Desktop 与 Web 均使用公开 stream base。
任务完成事件驱动结果传递，会话订阅驱动目录更新，本地输入框操作按 owner 定向通知，
不定时读取整个结果列表。旧宿主连接失败时退回 HTTP 查询。心跳与播放进度仍保留。
关闭语音结束该连接的远程订阅与操作归属；页面本地订阅不连接语音模型、不采集音频。

仅在发送会话初始化、音频和任务之前允许回退，成功建连后不跨地址重放。
服务忙、鉴权失败、版本拒绝不触发回退。模式切换会重新选择地址，既有连接不被推荐更新打断。
模型信息和通知跟随当前选中的地址；评分保留该次语音连接的目标地址，不跨服务重试写入。
连接诊断包含尝试地址、实际地址、选择方式和回退原因，不包含鉴权凭证。

连接诊断的字段白名单位于 `src/shared/diagnostics.mjs`，上传队列位于
`src/host/diagnostics.mjs`。支持 `client_diagnostics_v1` 的服务可接收麦克风与音频
启动阶段、首包、关闭原因及代理错误；连接要求服务支持此诊断协议，
缺少协议时明确提示服务版本需要更新，不静默降级。
上传为限量异步批次，同一事件去重，断开后的本地补报窗口为 30 秒；
网络或进程退出时不保证送达。远程诊断不含音频、设备名称、错误正文或堆栈，
不进入模型输入，也不因上报失败中断语音。

连接引导复用 `/api/connection-info` 的 `connection_hint`，同样每日后台刷新和持久化；
请求失败沿用缓存，旧接口或无效文案使用“连接成功，可以试试对我说‘你好’。”的内置提示。
只接受最多 200 字的单行纯文本，通过文本节点展示，不执行 HTML。
每次连接冻结文案、来源和配置 revision，随连接诊断记录；只有实际弹出时才记录
`browser.connection_hint_shown`。支持此能力的服务收到一次 `client.connection_hint` 展示上报，
旧服务不接收该事件。教学隐藏、播报模式或尚未就绪不计作展示。

## 本地存储

默认目录为 `DSH_HOME/dsh-duet/`，未指定 DSH_HOME 时为 `~/.dsh/dsh-duet/`。
设置 `voice.json`、反馈身份 `feedback-identity.key` 和推荐地址缓存
`endpoint-discovery.json` 首次使用时从旧 `duplex-control/` 目录复制，权限为 0600。
已有的新文件优先，旧文件保留，不迁移目录内其他文件；迁移失败时暂用旧文件，避免丢失身份或配置。
新日志写入 `dsh-duet/traces/`，旧日志保留原处，不在启动时搬动大文件。
显式设置的自定义文件和日志路径不变。HTTP 路径、Cookie 和浏览器存储键保持兼容。
