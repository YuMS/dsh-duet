# 源码导航

| 目录 | 内容 |
| --- | --- |
| `src/host/` | DSH 插件入口、会话操作、连接配置、反馈与静态资源注册 |
| `src/client/` | DSH 页面入口、音频、输入框同步、设置页和教学 |
| `src/shared/` | 模式状态与会话目录规则 |
| `config/` | DSH bundle 声明 |
| `assets/tutorial-audio/` | 教学音频与校验清单 |
| `tests/unit/` | 模块单元测试 |
| `tests/browser/` | 设置、教学和反馈的浏览器测试 |
| `tests/host/` | 隔离 DSH 安装与运行测试 |
| `scripts/` | 测试入口与发布内容检查 |

公开入口由 `package.json` 的 `exports` 和 `dsh.bundle` 指定，不依赖根目录文件名。
浏览器资源只从显式清单提供，不会把整个源码目录作为静态目录暴露。

## 命名与兼容

新增代码使用 `duet` 命名；代码模块使用短文件名，由目录表达职责。
地址等配置优先读取 `DUET_*`，旧环境变量仅在 `src/host/environment.mjs` 兼容。
公开试用访问凭证与默认地址统一放在 `src/host/service-defaults.mjs`；不读取本地或环境变量中的鉴权凭证。
该凭证仅用于内置服务地址，切换到其他服务不会携带它；连接配置文件只保存地址。

旧 HTTP 路径、协议字段、Cookie、浏览器存储键和互斥锁标识保持稳定，
确保升级不会清除授权、快捷键、麦克风选择或反馈身份，也不会让新旧页面同时采集音频。
旧浏览器模块地址由 `src/host/assets.mjs` 提供兼容导出；新页面使用 `/duet/assets/`。
`duplex` 作为全双工模型的协议字段仍保留，不是插件品牌名称。

两种语音模式都要求 DSH 已有 workspace：浏览器在授权和音频启动前检查，Host 在连接外部服务前再次检查。
会话编号由 `browserSessionCatalog` 统一供 RPC 与状态同步使用，排除归档及子代理会话。
DSH 0.1.5 使用其已保存的活动排序，0.1.6 的近期排序根据实时更新时间计算；手动排序保留页面设置。
待答问题同时支持 0.1.5 的 `pendingInteractions` 和 0.1.6 的 `sessionStatus.pendingInteraction`。

## 页面与连接归属

普通页面不发布或跟随全局会话焦点，也不响应跨页面输入框广播。
交互连接持有独立的 connection ID：读取和写入使用本页面输入框，发送队列通过
`X-Duet-Browser-Client` 定向给连接所属页面，其他页面及旧连接不能领取。
切换和分叉完成后只导航当前页面；断开连接会中止轮询及待处理的本地操作。
教学只在用户确认发送时临时开启定向桥接，不依赖语音模式，也不启用麦克风。

连接日志记录浏览器插件版本、Host 插件版本、随机页面 ID、连接 trace ID 和
`connection_owner_v1` 绑定协议。浏览器错误诊断另含时间、页面可见性、模式、错误码及
有限长度的异常栈；音频准备事件包含采样率、AudioContext 状态和浏览器 User-Agent。
这些归属标识不是鉴权凭证，不向模型正文注入诊断信息。

播报与交互连接共用 `duet_session_v1` 元信息：插件/Host 版本、模式、页面 ID、
连接 trace ID、页面绑定协议、实际连接地址和引导配置。旧页面缺少 trace ID 时生成
当次连接的随机 ID，不存为长期用户 ID。调度协议仍使用 `online` / `external_only`，
界面模式为 `online` / `tts_only`；两者不可混作 DSH 任务会话 ID。
语音初始化携带 Host 校验 Cookie 后取得的 `anonymous_user_id=anon_…`，
`identity_kind=anonymous_browser`；值与反馈的 `user_id` 一致，不包含账号身份或邮箱。
两种模式共用此来源，Cookie 缺失、无效或反馈身份服务不可用时省略字段，不阻断语音。
不接受浏览器在 URL/消息里自报身份，不另建长期 ID，也不将它作为鉴权凭证。
此标识可关联同一匿名浏览器的会话和反馈；清除 Cookie 或换浏览器可能改变标识。
授权版本保持 v3，两种模式共用一次同意。
DSH 会话目录、输入框和任务结果按既有功能传输，本次不增加播报模式的麦克风或草稿采集。

## 默认入口与连接选择

`DEFAULT_DUET_URL` 保持固定。公开服务从该入口的 `/api/connection-info` 获取推荐地址，
推荐地址持久化在 DSH_HOME/dsh-duet/endpoint-discovery.json。启动和连接时检查，
每 24 小时最多后台尝试刷新一次（失败也计入），连接不等待刷新。刷新失败保留旧推荐，
没有缓存时使用固定入口；推荐连接握手失败时回退固定入口。缓存不含凭证。
自定义服务不参与公开服务地址发现，也不会携带公开服务凭证。

仅在发送会话初始化、音频和任务之前允许回退，成功建连后不跨地址重放。
服务忙、鉴权失败、版本拒绝不触发回退。模式切换会重新选择地址，既有连接不被推荐更新打断。
模型信息和通知跟随当前选中的地址；评分保留该次语音连接的目标地址，不跨服务重试写入。
连接诊断包含尝试地址、实际地址、选择方式和回退原因，不包含鉴权凭证。

连接引导复用 `/api/connection-info` 的 `connection_hint`，同样每日后台刷新和持久化；
请求失败沿用缓存，旧接口或无效文案使用“连接成功，可以试试对我说‘你好’。”的内置提示。
只接受最多 200 字的单行纯文本，通过文本节点展示，不执行 HTML。
每次连接冻结文案、来源和配置 revision，随连接诊断记录；只有实际弹出时才记录
`browser.connection_hint_shown`。支持此能力的服务收到一次 `client.connection_hint` 展示上报，
旧服务不接收该事件。教学隐藏、播报模式或尚未就绪不计作展示。

## 本地存储

默认目录为 `DSH_HOME/dsh-duet/`，未指定 DSH_HOME 时为 `~/.dsh/dsh-duet/`。
设置 `voice.json`、反馈身份 `feedback-identity.key` 和推荐地址缓存
`endpoint-discovery.json` 首次使用时从旧 `duplex-control/` 目录复制，权限为 0600。
已有的新文件优先，旧文件保留，不迁移目录内其他文件；迁移失败时暂用旧文件，避免丢失身份或配置。
新日志写入 `dsh-duet/traces/`，旧日志保留原处，不在启动时搬动大文件。
显式设置的自定义文件和日志路径不变。HTTP 路径、Cookie 和浏览器存储键保持兼容。
