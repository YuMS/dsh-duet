# duet

duet 将**全双工语音交互模型带入 DeepSeek Harness（DSH）**，让你可以像用语音来使用 DSH。
它可以边听边说，你不必等它说完再开口：随时插话、补充需求、修改内容，让对话自然接续。
你可以用语音输入和提交任务、切换会话；任务完成后，dsh-duet 会简要播报结果。除此之外，你还可以跟 dsh-duet 聊聊天。

目前处于**试用阶段**，duet 语音服务无需配置 API Key，即可直接使用。
通过 DSH 提交任务所使用的模型仍遵循你自己的 DSH 配置与计费。

## 安装

已验证兼容 DSH `0.1.5-rc.2` 和 `0.1.6-alpha.2`。

安装并打开 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)：

```bash
npm install -g @deepseek-ai/dsh
dsh web
```

在另一个终端为 Web profile 安装插件，再重启 DSH：

```bash
dsh plugin --profile web add dsh-duet
dsh web
```

也支持 DSH 的 GitHub 插件安装方式：`dsh plugin --profile web add github:YuMS/dsh-duet`。
两种方式任选其一。

## 使用

页面上的 **duet** 提供两种模式，浅蓝色表示当前模式；点击另一按钮切换，再点当前按钮关闭。
默认两个模式都关闭。

| 按钮 | 模式 | 用途 |
| --- | --- | --- |
| 喇叭 | 播报模式 | 任务完成后，进行简短的播报 |
| 双向箭头 | 交互模式 | 开口操作 DSH、自由聊天，也可以在回复过程中插话 |

第一次使用可以跟随页面教学，也可以稍后从设置打开。

### 支持的语音操作

| 操作 | 你可以这样说 |
| --- | --- |
| 输入内容 | “输入，帮我整理一下这周的计划” |
| 修改内容 | “把这周改成下周” |
| 清空输入框 | “清空输入框” |
| 发送任务 | “发送”“提交” |
| 新建会话 | “新建一个会话，叫旅行计划” |
| 切换会话 | “切换到第二个会话”“切换到旅行计划” |
| 重命名会话 | “把当前会话改名为周末安排” |
| 分叉会话 | “从当前会话分叉一个新会话” |
| 归档会话 | “归档这个会话” |
| 自由聊天 | “什么是全双工语音交互？” |

输入和修改不会自动发送，检查内容后再说“发送”。任务结果会在完成后播报。
设置页还提供服务通知、教学和文字反馈，关闭语音时也可以为本次体验打分。

## 麦克风与隐私

duet 通过服务器提供语音服务。根据所使用的功能，以下信息会上传至服务器，用于理解语音、执行会话操作、生成回复和语音播报：

- 交互模式开启期间，麦克风采集的交互音频。
- 交互所需的会话信息，例如会话标识、名称、运行状态和当前选中的会话。
- 交互所需的输入框内容、任务结果及相关上下文。

关闭交互模式后，会停止采集和上传麦克风音频。
请勿在交互中提供密码、密钥等敏感内容。

**目前仅支持中文。**
