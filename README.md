# duet.

**DSH 语音操控和语音播报**

https://github.com/user-attachments/assets/83152138-c292-4057-a820-efc2bc96f33a

duet，意为「二重奏」。这里的 duet 使用全双工语音模型，可以边听边说，
让你与 DSH 的交流不必一人一句地等待。

说出需求，让 duet 帮你执行任务，或者把想法写进 DSH 输入框。你可以随时插话、补充或纠正。处理任务之外，也可以聊聊天。

当然，你也可以用 duet 帮你只播报结果，让你不用一直盯着屏幕。

现在，duet 还可以成为屏幕上的伙伴：听你说话、随声音回应，在任务完成或需要你处理时提醒你。

最重要的是，duet 语音服务目前可以免费使用。

## 安装

支持 DSH Web 和 Desktop。

### Web

需要 Node.js 22 LTS（22.19.0 起）或 24 及以上版本。

安装并打开 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)：

```bash
npm install -g @deepseek-ai/dsh
dsh web
```

在另一个终端为 Web profile 安装插件，再重启 DSH：

```bash
dsh plugin --profile web add dsh-duet
dsh web
```

### Desktop

在 DSH Desktop 的插件管理页面选择“添加插件”，输入 `dsh-duet` 并安装。
安装后若未出现 duet 按钮，退出并重新打开 DSH Desktop。

### 更新

Web 用户重新运行 `dsh plugin --profile web add dsh-duet@latest`，然后重启 DSH。
Desktop 用户在插件管理页面更新。

## 使用

### 选择工作方式

| 工作方式 | 适合怎样使用 |
| --- | --- |
| **代理模式** | 直接帮你执行任务。说出需求，duet 会安排任务、跟进进展，需要补充信息时再问你。 |
| **输入模式** | 帮你把需求输入文本框。可以修改内容，确认后再说“发送”，也可以用语音管理会话。 |

可以在设置中切换工作方式。使用代理模式时，先选择或创建一个工作区；推荐创建 dsh-duet 专属工作区。
代理模式需要你的授权，会以完整权限执行任务，包括运行命令、读写文件和访问网络。

### 开口交互，或只听播报

两种工作方式都支持交互和播报：

| 按钮 | 模式 | 用途 |
| --- | --- | --- |
| 喇叭 | 播报模式 | 任务完成后，进行简短的播报 |
| 双向箭头 | 交互模式 | 开口操作 DSH、自由聊天，也可以在回复过程中插话 |

首次启用声音时，按提示回到 DSH 页面点击“启用声音”；开始教学时点击“开始教学”。

### 3D 形象（实验）

点击头像按钮，打开或隐藏你的 duet 伙伴。可以让它悬浮在桌面，也可以在设置中选择“仅在网页端显示”，让角色出现在 DSH 侧栏上方。

本版桌面形象支持 macOS Apple Silicon 和 Windows x64，其他平台可使用网页形象。

字幕跟随声音，点头、摇头和嘴型让交流更直观。输入内容时，键盘气泡会显示正在写入的文字；教学、提示和确认也可以在角色旁完成。

右键桌面角色，可以调整大小、切换气泡样式、查看待处理事项或返回 DSH。不打开语音模式时，也可以通过角色查看任务通知。

你还可以在设置中给助手起个昵称，或直接用语音改名。

### 代理模式：直接交给 duet

| 操作 | 你可以这样说 |
| --- | --- |
| 开始任务 | “帮我整理一下这周的计划” |
| 继续修改 | “刚才那份计划，改成按天排列” |
| 询问进展 | “刚才的任务做得怎么样了？” |
| 回答追问 | “就用这周，把周末也算上” |
| 停止任务 | “停止刚才整理计划的任务” |

### 输入模式：用声音操作 DSH

| 操作 | 你可以这样说 |
| --- | --- |
| 输入内容 | “输入，帮我整理一下这周的计划” |
| 修改内容 | “把这周改成下周” |
| 清空输入框 | “清空输入框” |
| 发送任务 | “发送”“提交” |
| 停止任务 | “停止当前任务” |
| 新建会话 | “新建一个会话，叫旅行计划” |
| 切换会话 | “切换到第二个会话”“切换到旅行计划” |
| 重命名会话 | “把当前会话改名为周末安排” |
| 分叉会话 | “从当前会话分叉一个新会话” |
| 归档会话 | “归档这个会话” |
| 回答 DSH 的问题 | “选第二个”“用中文就好” |

两种工作方式下都可以自由聊天，也可以说“把你的名字改成沐沐”，给助手起个昵称。

## 麦克风与隐私

duet 通过服务器提供语音服务。根据所使用的功能，以下信息会上传至服务器，用于理解语音、执行会话操作、生成回复和语音播报：

- 交互模式开启期间，麦克风采集的交互音频。
- 交互所需的会话信息，例如会话标识、名称、运行状态和当前会话名称。
- 交互所需的输入框内容、任务结果。

请勿在交互中提供密码、密钥等敏感内容。

**目前仅支持中文。**
